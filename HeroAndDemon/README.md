# HeroAndDemonGame
・勇者と魔王ゲーム(個人でやるかも)<br>
完全ランダムの能力・技から選んでキャラクリエイト　ターン制バトル　戦略性あり<br>
　←→マスターモード　全てから選ぶ<br>
お互いに弱点を選ぶ必要がある<br>
弱点、デメリット付きの強力なスキル<br>
１、キャラクリ<br>
２、バトル<br>
基本的に魔王の方が強い & 勇者は3回リタマラ・リセマラできる<br>
１セット３バトルで一回でも勇者が勝てば勝ち<br>
<br>
構成自体はシンプルで、能力・技などゲームの広がりを重視・重点的に開発<br>
いろんなキャラ構成を実現できるようにしたい<br>
<br>
