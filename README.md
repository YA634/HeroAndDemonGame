# HeroAndDemonGame
・勇者と魔王ゲーム(個人でやるかも)
完全ランダムの能力・技から選んでキャラクリエイト　ターン制バトル　戦略性あり
　←→マスターモード　全てから選ぶ
お互いに弱点を選ぶ必要がある
弱点、デメリット付きの強力なスキル
１、キャラクリ
２、バトル
基本的に魔王の方が強い & 勇者は3回リタマラ・リセマラできる
１セット３バトルで一回でも勇者が勝てば勝ち

構成自体はシンプルで、能力・技などゲームの広がりを重視・重点的に開発
いろんなキャラ構成を実現できるようにしたい

使用技術
・Python or Java
・JavaScript or その他
・(PostgreSQL)
